## Descripción

Morse code is well known. Can you decrypt this? Download the file [here](https://challenge-files.cylabacademy.net/library/3728bfa4e8314fddd6b7e9f3fae9cb453b459a0bd4b3a29a9224701152f0cd89/morse_chal.wav).

Wrap your answer with academy{}, put underscores in place of pauses, and use all uppercase.

pistas:

1. Audacity is a really good program to analyze morse code audio.
## Solución

```
- Descargué el archivo `morse_chal.wav` proporcionado por el reto.
    
- Abrí la página [Morse Code Audio Decoder]
    
- Subí el archivo de audio para convertir las señales Morse a texto.
    
- Obtuve el mensaje `WH47 H47H 90D W20U9H7`.
    
- Reemplacé los espacios por guiones bajos, conservé las letras en mayúsculas y agregué el formato `academy{}` solicitado por la plataforma.
    
- Envié la flag obtenida:
  academy{WH47_H47H_90D_W20U9H7}
```
