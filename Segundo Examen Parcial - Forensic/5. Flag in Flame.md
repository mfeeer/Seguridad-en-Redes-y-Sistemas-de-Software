## Descripción
The SOC team discovered a suspiciously large log file after a recent breach. When they opened it, they found an enormous block of encoded text instead of typical logs. Could there be something hidden within?
Download the encoded data here: [Logs Data](https://challenge-files.cylabacademy.net/library/ad9f6c5d3cb51fb2e93e1f082064d16373daecd3fb37e05650e5a530179ccf68/logs.txt).

pistas:
1. Use `base64` to decode the data and generate the image file.
## Solución
```
- Descargamos el archivo
wget https://challenge-files.cylabacademy.net/library/ad9f6c5d3cb51fb2e93e1f082064d16373daecd3fb37e05650e5a530179ccf68/logs.txt
head -c 60 logs.txt

- Decodificamos a imagen
base64 -d logs.txt > flame.png
file flame.png      -> PNG image data, 896 x 1152

- Abrimos la imagen: abajo aparece un texto en hexadecimal
61636164656D797B666F72656E736963735F616E616C797369735F69735F616D617A696E675F61626531643662617D

- Lo convertimos de hex a ASCII
echo 61636164656D797B666F72656E736963735F616E616C797369735F69735F616D617A696E675F61626531643662617D | xxd -r -p

- encontramos la flag:
academy{forensics_analysis_is_amazing_abe1d6ba}
```
