## Descripción
Download this image file and find the flag.
- [Download image file](https://challenge-files.cylabacademy.net/library/248587d9a868db74a285623697f78ef3d87561aaa16ff1fb211fe88cd72f4a6c/drawing.flag.svg)
## Solución
```
- Descargamos la imagen SVG
wget https://challenge-files.cylabacademy.net/library/248587d9a868db74a285623697f78ef3d87561aaa16ff1fb211fe88cd72f4a6c/drawing.flag.svg

- Un SVG es XML (texto), así que se puede leer. La flag está en etiquetas
  <tspan> con letra diminuta, por eso no se ve en la imagen
grep -o '<tspan[^>]*>[^<]*</tspan>' drawing.flag.svg | sed 's/<[^>]*>//g' | tr -d '\n'

- salida: a c a d e m y { 3 n h 4 n c 3 d _ 0 0 1 f 8 0 5 9 }
- quitamos los espacios y encontramos la flag:
academy{3nh4nc3d_001f8059}
```
