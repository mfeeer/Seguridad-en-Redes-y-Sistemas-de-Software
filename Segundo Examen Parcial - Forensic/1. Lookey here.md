## Descripción
Attackers have hidden information in a very large mass of data in the past, maybe they are still doing it.
Download the data [here](https://challenge-files.cylabacademy.net/library/1461fca1c694c5c9ca0fb1fe427c36f56d80f5f23eb617a51c95fe1b6ca5ed83/anthem.flag.txt).

pistas:
1. Download the file and search for the flag based on the known prefix.
## Solución
```
- Descargamos el archivo (es un texto enorme, un "himno")
wget https://challenge-files.cylabacademy.net/library/1461fca1c694c5c9ca0fb1fe427c36f56d80f5f23eb617a51c95fe1b6ca5ed83/anthem.flag.txt

- Buscamos el prefijo conocido de la flag con grep
grep -o 'academy{[^}]*}' anthem.flag.txt

- encontramos la flag:
academy{gr3p_15_@w3s0m3_375ef577}
```
## Notas adicionales
`grep -o` imprime solo la parte que coincide con la expresión regular, no toda la línea.
