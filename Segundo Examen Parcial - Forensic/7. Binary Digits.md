## Descripción
This file doesn't look like much... just a bunch of 1s and 0s. But maybe it's not just random noise. Can you recover anything meaningful from this?
Download the file [here](https://challenge-files.cylabacademy.net/library/fa557c211c0530127695e5c025ad525fb44b6d41809745cba5f13db15f2a41fe/digits.bin).
## Solución
```
- Descargamos el archivo: es texto con solo 0 y 1
wget https://challenge-files.cylabacademy.net/library/fa557c211c0530127695e5c025ad525fb44b6d41809745cba5f13db15f2a41fe/digits.bin
head -c 32 digits.bin   -> 11111111110110001111111111100000 = FF D8 FF E0 (cabecera JPEG)

- Convertimos cada grupo de 8 bits a un byte con python:
python3 -c "
b=open('digits.bin').read().strip()
open('salida.jpg','wb').write(int(b,2).to_bytes(len(b)//8,'big'))"
file salida.jpg   -> JPEG image data, 800x500

- Abrimos la imagen y aparece la flag:
academy{h1dd3n_1n_th3_b1n4ry_1b150ee9}
```
