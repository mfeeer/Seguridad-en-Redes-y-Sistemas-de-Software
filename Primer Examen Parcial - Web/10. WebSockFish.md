## Descripción
Can you win in a convincing manner against this chess bot? He won't go easy on you! You can find the challenge [here](http://xebec.cylabacademy.net:36623/).

pistas:

1. Try understanding the code and how the websocket client is interacting with the server
## Solución
- se ingresó al sitio del reto y se abrió la consola del navegador con `F12` para revisar la comunicación del juego mediante WebSocket.
- Se identificó que era posible enviar directamente una evaluación de la partida al servidor. En la consola se ejecutó:

```
ws.send("eval -99999")
```

-  La evaluación negativa hizo que el servidor considerara que el bot estaba perdiendo la partida, por lo que se rindió automáticamente.
-  Como resultado, el juego mostró la flag del reto, sin necesidad de ganar la partida jugando ajedrez de forma convencional.
