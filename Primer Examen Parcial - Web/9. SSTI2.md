## Solución

- Se ingresó al sitio y se comprobó la vulnerabilidad SSTI utilizando expresiones como `{{7*7}}` y `{{request}}`, verificando que el servidor procesaba las plantillas.
- Como la aplicación tenía un filtro para bloquear caracteres y expresiones peligrosas, se utilizó una técnica de evasión mediante `attr()` y representaciones alternativas de los caracteres bloqueados.
- se empleó un payload que permitió acceder a funciones del sistema y ejecutar `cat flag`, obteniendo así la flag del reto.

## Notas adicionales
El filtro `attr()` permite acceder a atributos de un objeto sin usar el punto (`.`). El método `__getitem__` permite acceder a elementos de un diccionario o lista sin usar corchetes (`[]`)
