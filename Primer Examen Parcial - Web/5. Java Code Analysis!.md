## Notas adicionales
- **JSON Web Token (JWT):** Los JWT son un estándar para transmitir información de forma segura entre partes. Sin embargo, si la clave secreta utilizada para firmar los tokens es débil o predecible (como `"1234"`), un atacante puede falsificar tokens válidos. Esto se conoce como **JWT Forgery** o **Weak Secret Key Vulnerability**.
