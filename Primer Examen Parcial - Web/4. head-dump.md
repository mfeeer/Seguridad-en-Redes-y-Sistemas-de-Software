## Descripción

Welcome to the challenge! In this challenge, you will explore a web application and find an endpoint that exposes a file containing a hidden flag.

The application is a simple blog website where you can read articles about various topics, including an article about API Documentation. Your goal is to explore the application and find the endpoint that generates files holding the server’s memory, where a secret flag is hidden. The website is running [picoCTF News](http://xebec.cylabacademy.net:48417/).

pistas:
1. Explore backend development with us

2. The head was dumped.
## Solución
Entrar a la página y  descargar el archivo headdump y inspeccionarlo para conseguir la flag

- Entrar al link que se proporciona en el reto, después entrar a "Api Documentation", y buscar el nombre del reto headdump, alli descargar el archivo que aparece y buscar con un grep "picoCTF" o "academy" y con ello obtener la flag
