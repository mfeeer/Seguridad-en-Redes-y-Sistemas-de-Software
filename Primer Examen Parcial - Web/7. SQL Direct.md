## Solución
1. Se instaló el cliente de PostgreSQL y se realizó la conexión al servidor del reto con:

```
sudo apt update
sudo apt install postgresql-client -y
psql -h chatelaine.cylabacademy.net -p 28130 -U postgres pico
```

La contraseña utilizada fue `postgres`.

2. Una vez dentro de PostgreSQL, se revisaron las tablas disponibles con:

```
\dt
```

3. Se consultó la tabla que contenía la información del reto con:

```
SELECT * FROM flags;
```

De esta forma se obtuvo la flag directamente desde la base de datos.
