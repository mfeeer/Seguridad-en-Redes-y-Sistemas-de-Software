## Solución

- Se ingresó al sitio del reto y se probó el campo de anuncio con `{{7*7}}`. Al obtener `49` como resultado, se comprobó que la página estaba interpretando expresiones de plantilla.
- Se identificó que el sitio utilizaba Jinja2 y se aprovechó la vulnerabilidad SSTI para acceder a funciones del servidor mediante una expresión especialmente diseñada.
- Finalmente, se utilizó el payload para ejecutar el comando `cat flag` desde el servidor y así obtener la flag del reto.
