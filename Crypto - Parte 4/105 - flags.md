## Descripción
What do the [flags](https://challenge-files.cylabacademy.net/library/187296d0c352a8451662153842fc9794b9f247a1ac949978113ddfcb9a1bb76f/flag.png) mean?

The flag is in the format PICOCTF{}
## Solución

```
Nuestra imagen sugiere un reto donde debemos de manejar banderas para decodificar el mensaje que se nos pone enfrente, al final conseguiremos el siguiente mensaje

picoCTF{F1AG5AND5TUFF}
```
## Notas adicionales
se usó Navy Signal Flags Translator para decodificar el mensaje
