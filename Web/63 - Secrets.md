
## Descripción

We have several pages hidden. Can you find the one with the flag? The website is running [here](http://chatelaine.cylabacademy.net:14501/).

pistas:
1.   folders folders folders
## Solución
para este reto la pista es: carpetas, por lo que al inspeccionar el codigo podemos ver que:
- existe una carpeta comprimida llamada secret
- Entramos a la carpeta secret  /secret/
- Vemos otra carpeta llamada hidden
- Entramos otra vez a la carpeta  /secret/hidden/
-  al entrar, vemos otra carpeta llamada superhidden
- Entramos otra vez a la carpeta  /secret/hidden/superhidden/
- Encontramos la flag después del texto de "can you see me"
