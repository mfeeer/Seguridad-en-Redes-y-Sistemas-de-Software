## Descripción
What does asm3(0xddf64382,0xf00e4217,0xc3fb804e) return? Submit the flag as a hexadecimal value (starting with '0x'). NOTE: Your submission for this question will NOT be in the normal flag format. [Source](https://challenge-files.cylabacademy.net/library/001c522fa43014c415d9b20b85d5680048f31a5daa89f581f7a63eaf58b6969d/test.S)
## Solución

```
1. `xor eax,eax` → eax = 0
2. `mov ah, [ebp+0xa]` → ah = `0xf6` (byte en arg1) → ax = `0xf600`
3. `shl ax, 0x10` → desplazar **16** bits una palabra de **16** bits saca todos los bits → ax = `0x0000` (el truco clave del reto: esto borra todo lo anterior)
4. `sub al, [ebp+0xd]` → al = `0x00 - 0x42` (byte en arg2) = `0xBE`
5. `add ah, [ebp+0xf]` → ah = `0x00 + 0xf0` (byte en arg2) = `0xF0`  
    → ax = `0xF0BE`
6. `xor ax, [ebp+0x12]` → word en `ebp+0x12` = bytes `fb c3` → `0xC3FB`  
    → `0xF0BE ^ 0xC3FB = 0x3345`
```
