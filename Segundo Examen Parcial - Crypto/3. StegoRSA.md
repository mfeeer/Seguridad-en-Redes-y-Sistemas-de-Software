## Descripción
A message has been encrypted using RSA. The public key is gone… but someone might have been careless with the private key. Can you recover it and decrypt the message?
Download the [flag](https://challenge-files.cylabacademy.net/library/f237dbe3d9649dccd19ec1ae56a3380afa24e1960376a1b9c59cbb234ac22ef5/flag.enc) and [image](https://challenge-files.cylabacademy.net/library/f237dbe3d9649dccd19ec1ae56a3380afa24e1960376a1b9c59cbb234ac22ef5/image.jpg).

pistas:
1. Metadata can tell you more than you expect.
2. Hex can be turned back into a key file.
## Solución
```
- Descargamos los dos archivos
wget https://challenge-files.cylabacademy.net/library/f237dbe3d9649dccd19ec1ae56a3380afa24e1960376a1b9c59cbb234ac22ef5/flag.enc
wget https://challenge-files.cylabacademy.net/library/f237dbe3d9649dccd19ec1ae56a3380afa24e1960376a1b9c59cbb234ac22ef5/image.jpg

- En los metadatos, el campo Comment tiene un texto hexadecimal muy largo
exiftool image.jpg
Comment : 2d2d2d2d2d424547494e2050524956415445204b45592d2d2d2d2d0a...

- 2d2d2d2d2d = "-----", así que es una llave PEM en hex. La convertimos a archivo:
exiftool -b -Comment image.jpg | xxd -r -p > private.pem
head -1 private.pem    -> -----BEGIN PRIVATE KEY-----

- Desciframos flag.enc con la llave privada
openssl pkeyutl -decrypt -inkey private.pem -in flag.enc

- encontramos la flag:
academy{rs4_k3y_1n_1mg_9db27b2c}
```
