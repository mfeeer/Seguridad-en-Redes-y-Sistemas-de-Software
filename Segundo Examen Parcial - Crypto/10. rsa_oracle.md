## Descripción
Can you abuse the oracle?

An attacker was able to intercept communications between a bank and a fintech company. They managed to get the [message](https://challenge-files.cylabacademy.net/library/cc9c4d299ce0771659ad7cb4572565ac419c807cc701bad4ab0dbe841f18f95c/secret.enc) (ciphertext) and the [password](https://challenge-files.cylabacademy.net/library/cc9c4d299ce0771659ad7cb4572565ac419c807cc701bad4ab0dbe841f18f95c/password.enc) that was used to encrypt the message.
After some intensive reconassainance they found out that the bank has an oracle that was used to encrypt the password and can be found here `nc xebec.cylabacademy.net <puerto>`. Decrypt the password and use it to decrypt the message. The oracle can decrypt anything except the password.

pistas:
1. Crytography Threat models: chosen plaintext attack.
2. OpenSSL can be used to decrypt the message. e.g `openssl enc -aes-256-cbc -d ...`
3. The key to getting the flag is by sending a custom message to the server by taking advantage of the RSA encryption algorithm.
4. Minimum requirements for a useful cryptosystem is CPA security.
## Solución

RSA "de libro" es **maleable**: `E(a) * E(b) = (a*b)^e = E(a*b) mod n`. El oráculo no descifra el password directamente, pero sí descifra `c_password * E(2)`, que equivale a `2 * password`.

```
- Lanzamos la instancia y nos conectamos
nc xebec.cylabacademy.net <puerto>

- Opción E: ciframos el byte \x02 (m = 2) y guardamos el resultado c2
- Opción D: mandamos c_password * c2 (multiplicación normal de los dos enteros)
  respuesta (hex): 646a706470

- Dividimos entre 2 para obtener el password
python3 -c "print(bytes.fromhex(hex(0x646a706470 // 2)[2:]).decode())"
-> 25828

- Desciframos el mensaje con openssl
openssl enc -aes-256-cbc -d -in secret.enc -k 25828
```

Script que hace todo el ataque automáticamente:

```python
import socket, time, re
c_pw = int(open('password.enc').read())
s = socket.create_connection(('xebec.cylabacademy.net', 37043))   
def rd(): time.sleep(1.5); return s.recv(65536).decode()
rd()
s.sendall(b'E\n'); rd(); s.sendall(b'\x02\n')
c2 = int(re.search(r'\(m \^ e mod n\) (\d+)', rd()).group(1))
s.sendall(b'D\n'); rd()
s.sendall(str(c_pw * c2).encode() + b'\n')
print(rd())  
```

## Notas adicionales
Este es un ataque de texto cifrado elegido (chosen ciphertext). Se evita usando padding como OAEP.
