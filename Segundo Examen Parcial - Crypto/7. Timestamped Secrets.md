## Descripción
Someone encrypted a message using AES in ECB mode but they weren't very careful with their key. Turns out it's derived from something as simple as the current time! Can you uncover the key and decrypt the flag?

## Solución

La llave AES es `sha256(str(timestamp))[:16]`, y `message.txt` nos dice el timestamp aproximado (`1790147508`). Probamos timestamps alrededor de ese valor hasta que el texto descifrado empiece con `academy{`.

```python
from hashlib import sha256
from Cryptodome.Cipher import AES   
ts = 1790147508
ct = bytes.fromhex("1677f86f41155474ff5233bc79d0ec79ab610074d921fea1140a448f8c8329d9")
for t in range(ts - 100000, ts + 100000):
    key = sha256(str(t).encode()).digest()[:16]
    pt = AES.new(key, AES.MODE_ECB).decrypt(ct)
    if pt.startswith(b"academy{"):
        print(t, pt)
        break
```
