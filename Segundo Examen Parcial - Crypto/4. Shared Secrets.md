## Descripción
A message was encrypted using a shared secret... but it looks like one side of the exchange leaked something. Can you piece together the secret and get the flag?
Download the [message](https://challenge-files.cylabacademy.net/library/70415f267476bdaa5762bdd5dce4d587950c58d1a6105e1244310679bd20de4d/message.txt). And source [code](https://challenge-files.cylabacademy.net/library/70415f267476bdaa5762bdd5dce4d587950c58d1a6105e1244310679bd20de4d/encryption.py)

pistas:
1. What do you get if you combine a public key with a known private one?
## Solución

Es un intercambio Diffie-Hellman. `message.txt` trae `g`, `p`, la llave pública del servidor `A` y **la llave privada del cliente `b`** (la fuga). El secreto compartido es `A^b mod p`, y la flag se cifró con XOR usando `shared % 256` (un solo byte).

```python
import re
d = dict(re.findall(r'^(\w+) = (\S+)', open('message.txt').read(), re.M))
shared = pow(int(d['A']), int(d['b']), int(d['p']))
k = shared % 256
print(bytes(x ^ k for x in bytes.fromhex(d['enc'])))
```

encontramos la flag:
academy{dh_s3cr3t_2f0e1b6c}
## Notas adicionales
Con solo un byte de llave XOR también se podía sacar por fuerza bruta (256 opciones).
