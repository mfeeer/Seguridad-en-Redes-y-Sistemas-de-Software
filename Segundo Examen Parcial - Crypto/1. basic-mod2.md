## Descripción
A new modular challenge! Download the message [here](https://challenge-files.cylabacademy.net/library/8493f8b1c07d84e858fa52d3dacdc63752275286da7a30b69fab36993eafb5ea/message.txt).

Take each number mod 41 and find the modular inverse for the result. Then map to the following character set: 1-26 are the alphabet, 27-36 are the decimal digits, and 37 is an underscore.

Wrap your decrypted message in the academy flag format (i.e. `academy{decrypted_message}`)

pistas:
1. Do you know what the modular inverse is?
2. The inverse modulo *z* of *x* is the number, *y* that when multiplied by *x* is 1 modulo *z*
3. It's recommended to use a tool to find the modular inverses
## Solución

Usamos este script (`pow(x, -1, 41)` calcula el inverso modular en Python 3.8):

```python
message = "432 126 192 354 98 296 272 311 146 297 364 373 262 277 215 377 255 407 72 46 213 448 212"
alfabeto = "ABCDEFGHIJKLMNOPQRSTUVWXYZ0123456789_"
resultado = "academy{"
for num in message.split():
    inv = pow(int(num) % 41, -1, 41)
    resultado += alfabeto[inv - 1] 
resultado += "}"
print(resultado)
```
