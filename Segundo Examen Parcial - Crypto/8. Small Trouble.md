## Solución

En `encryption.py` el exponente privado `d` es un primo de solo **256 bits**, mientras que `n` mide ~2096 bits. Como `d < n^0.25 / 3`, alcanza con el **ataque de Wiener** (no hizo falta Boneh-Durfee): se calculan las fracciones continuas de `e/n` y uno de los convergentes `k/d` revela `d`.

```python
import re
from Cryptodome.Util.number import long_to_bytes

d_ = dict(re.findall(r'^(\w+) = (\S+)', open('message.txt').read(), re.M))
n, e, c = int(d_['n']), int(d_['e']), int(d_['c'])

def fraccion_continua(a, b):
    while b:
        q = a // b
        yield q
        a, b = b, a - q * b

h0, h1, k0, k1 = 0, 1, 1, 0
for q in fraccion_continua(e, n):
    h0, h1 = h1, q * h1 + h0      
    k0, k1 = k1, q * k1 + k0     
    m = long_to_bytes(pow(c, k1, n))
    if m.startswith(b'academy{'):
        print(m)
        break
```
