## Descripción
Our data got corrupted on the way here. Luckily, nothing got replaced, but every block of 3 got scrambled around! The first word seems to be three letters long, maybe you can use that to recover the rest of the message.
Download the corrupted message [here](https://challenge-files.cylabacademy.net/library/304dc08e455ad3c33cf532bb41f44a7e939e8e2ad161d9c9012b8375dee48829/message.txt).

pistas:
1. Split the message up into blocks of 3 and see how the first block is scrambled
## Solución
```
- Contenido del archivo:
heTfl g as icaaemd{7y4NRP051N5_16_35P3X51N3_V1CCA2B2}A

- El primer bloque "heT" debería ser "The": el 3er carácter va primero,
  luego el 1ro y luego el 2do. Aplicamos eso a cada bloque de 3:
```
```python
t = open('message.txt').read()
print(''.join(t[i+2] + t[i] + t[i+1] for i in range(0, len(t), 3)))
```
```
- salida: The flag is academy{7R4N5P051N6_15_3XP3N51V3_C1CBA2A2}

- encontramos la flag:
academy{7R4N5P051N6_15_3XP3N51V3_C1CBA2A2}
```
