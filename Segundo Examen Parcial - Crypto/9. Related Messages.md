## Solución

`output.txt` trae `c1`, `c2`, la diferencia `M - M_fixed = -3` y `N`, con `e = 17`. Los dos mensajes están relacionados linealmente (`M = M_fixed - 3`), así que aplica el **Franklin-Reiter related message attack**:

- `f1(x) = (x - 3)^17 - c1` y `f2(x) = x^17 - c2` tienen como raíz común `x = M_fixed`.
- El MCD de los dos polinomios módulo N es `(x - M_fixed)`, y de ahí sale el mensaje.

```python
from math import comb
from Cryptodome.Util.number import long_to_bytes

c1, c2, diff, N = map(int, open('output.txt').read().split()[:4])
E = 17

def normalizar(f):
    while f and f[-1] % N == 0: f.pop()
    return f
def pmod(f, g):                     
    f = f[:]; inv = pow(g[-1], -1, N)
    while len(f) >= len(g):
        q = f[-1] * inv % N; s = len(f) - len(g)
        for i in range(len(g)): f[s + i] = (f[s + i] - q * g[i]) % N
        normalizar(f)
    return f
def pgcd(f, g):
    while g: f, g = g, pmod(f, g)
    return f


f1 = [comb(E, i) * pow(diff, E - i, N) % N for i in range(E + 1)]; f1[0] = (f1[0] - c1) % N
f2 = [0] * (E + 1); f2[E] = 1; f2[0] = (-c2) % N
g = pgcd(f2, f1)                    
m_fixed = (-g[0] * pow(g[1], -1, N)) % N
print(long_to_bytes(m_fixed))       
print(long_to_bytes(m_fixed + diff)) 
```
