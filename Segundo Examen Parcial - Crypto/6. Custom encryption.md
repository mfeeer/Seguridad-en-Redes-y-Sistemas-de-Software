## Solución

Analizando `custom_encryption.py`, el cifrado hace:
1. Diffie-Hellman con p=97, g=31 y los valores a, b dados en `enc_flag` (a=95, b=31) → `shared_key`.
2. `dynamic_xor_encrypt`: **invierte** el texto y le hace XOR con la llave "trudeau".
3. `encrypt`: multiplica cada carácter por `shared_key * 311`.

Para descifrar se hace todo al revés: dividir entre `key*311`, hacer XOR con "trudeau" y voltear el resultado.

```python
p, g, a, b = 97, 31, 95, 31
v = pow(g, b) % p
key = pow(v, a) % p            
cipher = [134352, 343344, 238848, 1194240, 0, 1298736, 1059888, 1134528, 1059888, 626976, 0, 1239024, 313488, 74640, 1015104, 0, 328416, 1283808, 14928, 925536, 358272, 403056, 89568, 89568, 253776, 89568, 388128, 179136, 373200, 343344, 253776, 74640, 89568, 0]
semi = ''.join(chr(c // (key * 311)) for c in cipher)
tk = "trudeau"
plain = ''.join(chr(ord(ch) ^ ord(tk[i % len(tk)])) for i, ch in enumerate(semi))
print(plain[::-1])
```
