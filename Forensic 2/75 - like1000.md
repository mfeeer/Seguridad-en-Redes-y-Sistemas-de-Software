## Descripción

This [.tar file](https://challenge-files.cylabacademy.net/library/0fcc092f4e3d0027bc89f6de85e2b750462dca0a96c5643e38e5825e2da1c3d2/1000.tar) got tarred a lot.

1. Try and script this, it'll save you a lot of time
## Solución

Al descargar nuestro archivo, vemos que es un archivo comprimido sobre otro archivo comprimido (básicamente del 1000 al 1) por lo que se aplicará un script como el siguiente:

```
for i in {1000..1}; do tar -xvf "$i.tar"; done
open flag.png
```

y obtenemos la flag correspondiente
